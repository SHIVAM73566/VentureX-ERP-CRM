INTERACTIONS (all pure HTML/CSS/JS, no backend)
═══════════════════════════════════════════

1. SIDEBAR NAVIGATION: clicking any sidebar item shows that page's content div, hides others. Use data-page attributes and JS class toggling.

2. LOGIN → DASHBOARD: login button triggers 1s spinner, then hides login page div and shows app layout div.

3. LOGOUT: dropdown "Logout" hides app layout, shows login page div.

4. Kanban cards (Leads/Tickets): visual hover lift effect only (translateY -2px, shadow increase).

5. Charts: use CSS-only bar charts (div heights as percentages) OR include Chart.js CDN (single file allowed) for the dashboard revenue chart. Keep lightweight.

6. Tabs (Settings, Invoice filters): click tab = show that tab's content panel.

7. Search bar: on keyup, filter the current table rows by matching visible text (simple JS filter).

8. Tables: sortable columns (click header = sort by that column, toggle asc/desc).

9. Notifications bell: clicking shows a dropdown with 3 notification items.

10. Sidebar collapse: clicking hamburger makes sidebar 60px wide (icons only, text hidden). Click again = restore.

11. Dark mode toggle: switches CSS variables to dark palette. Persist via localStorage.

12. RESPONSIVE: on screens < 768px, sidebar becomes a slide-out drawer (hamburger opens it as overlay). Top bar becomes fixed.

13. SMOOTH TRANSITIONS: page content fades in (opacity 0→1, 200ms) when switching pages.
