## DESCRIPTION

VentureX ERP & CRM is a complete AI-powered business operating system built with Laravel 13. It combines CRM, sales pipeline, inventory management, procurement, accounting, logistics, and customer support into one professional platform with an integrated AI copilot.

**Perfect for:** Small to medium businesses, agencies, freelancers, SaaS startups.

### QUICK START

1. Download and extract the ZIP
2. Run `composer install`
3. Run `npm install && npm run build`
4. Copy `.env.example` to `.env`
5. Run `php artisan key:generate`
6. Create MySQL database
7. Run `php artisan migrate --seed`
8. Run `php artisan serve`
9. Open http://localhost:8000

**Or use the web installer:** Upload to your server, visit `/install`
