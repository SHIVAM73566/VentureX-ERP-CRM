Step 2:
Configure Your Environment
We'll set up the .env file with your database credentials and application settings.
Copy .env.example to .env
Start with the provided template
Terminal
# Navigate to your project directory
$ cd venturex-crm-erp
# Copy the example environment file
$ cp .env.example .env
✓ .env file created from template
Note: On Windows, use copy .env.example .env instead of cp.
Open the .env File
Open it in your favorite code editor
Terminal
# Open in VS Code
$ code .env
# Or use any text editor
$ nano .env
$ vim .env
Database Configuration
Enter the credentials you created in the previous video
.env
1# ─── Database Configuration ───
2DB_HOST=127.0.0.1
3DB_PORT=3306
4DB_DATABASE=venturex_erp
5DB_USERNAME=venturex_user
6DB_PASSWORD=your_secure_password
7# ...
Set App Name
Name your installation
.env
1# ─── Application Settings ───
2APP_NAME="VentureX CRM & ERP"
3APP_ENV=local
4APP_DEBUG=true
5# ...
Set App URL
Configure the application URL
.env
1# ─── Application URL ───
2APP_URL=http://localhost:8000
3
4# For production, change to your domain:
5# APP_URL=https://yourdomain.com
AI Provider Keys (Optional)
Configure AI features — skip if not needed
.env
1# ─── AI Configuration (Optional) ───
2AI_PROVIDER=openai
3OPENAI_API_KEY=sk-your-key-here
4OPENAI_MODEL=gpt-4
5# Supports: openai, anthropic, ollama
6# Leave blank to disable AI features
Note: AI features work without any API key when using Ollama (local). Just set AI_PROVIDER=ollama.
Generate APP_KEY
Laravel needs an encryption key for secure sessions and tokens
Terminal
# Generate the application encryption key
$ php artisan key:generate
Application key set successfully.
✓ APP_KEY generated and added to .env
✓
Configuration Complete!
Your .env is configured. The final step — installing all dependencies.
