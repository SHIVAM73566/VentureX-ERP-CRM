## Description

```
VentureX ERP & CRM is a complete, production-ready AI-powered business operating system built on Laravel 13 with PHP 8.4. It combines CRM, sales, invoicing, inventory, procurement, logistics, finance, AI copilot, and support ticketing into a single unified platform — designed for agencies, trading companies, wholesalers, distributors, and growing businesses.

Unlike SaaS ERP tools that lock you into monthly subscriptions, VentureX is a one-time purchase. You own the full source code, host it on your own server, and get unlimited users with no per-seat fees.

WHAT'S INCLUDED

Full source code with 62+ Controllers, 64+ Models, 32+ Services, 39 Database Migrations, 125+ Blade Views, 220+ Routes, and 32 Authorization Policies. Complete documentation, Docker configs, installation wizard, and demo data seeder included.

AI COPILOT (WORKS WITHOUT API KEYS)

Built-in natural language AI assistant that works out-of-the-box with local intelligence. No API key required. Optional upgrade to NVIDIA Nemotron, Gemini, OpenAI, or Claude for enhanced responses.

CORE MODULES

CRM — Customers, contacts, leads, opportunities, sales pipeline, activities
Sales — Quotations, sales orders, invoices, payments, PDF generation
Inventory — Products, warehouses, stock movements, SKU management
Procurement — Purchase requisitions, purchase orders, RFQs, supplier offers
Finance — Chart of accounts, journal entries, receivables, payables, dashboards
Logistics — Shipments, containers, landed costs
Support — Help center, ticket system, error reporting, documentation
Admin — Users, roles, settings, import/export, audit logs, system health

AI FEATURES

Natural language chat assistant, AI Copilot with context-aware suggestions, AI Support Assistant with built-in knowledge base, AI Document Reader for file analysis, AI Procurement intelligence, rule-based business insights, multi-provider support (NVIDIA, Gemini, OpenAI, Claude, DeepSeek).

SECURITY

Multi-Factor Authentication (TOTP), Role-Based Access Control with granular permissions, 10-layer security architecture, emergency lockdown mode, complete audit logging, rate limiting, brute force protection, device trust management, session management, GDPR/CCPA compliance.

TECHNICAL STACK

Laravel 13 + PHP 8.4+, Blade + Alpine.js + Tailwind CSS v4, MySQL 8.0+ / MariaDB 10.6+, Vite 8.x build system, Apache 2.4+ / Nginx 1.24+, Docker & Docker Compose configs, 339 PHPUnit tests (464 assertions, 0 failures).

SELF-HOSTED. ONE-TIME PURCHASE. UNLIMITED USERS. FULL SOURCE CODE.
```

## Instructions

```
INSTALLATION (6 Steps)

Step 1: Server Requirements
- PHP 8.4+ with extensions: pdo_mysql, mbstring, openssl, tokenizer, xml, ctype, json, bcmath, gd, zip
- MySQL 8.0+ or MariaDB 10.6+
- Composer 2.x
- Node.js 18+
- Web server: Apache 2.4+ or Nginx 1.24+

Step 2: Upload & Extract
Upload the ZIP to your server and extract:
cd /var/www/html
unzip VentureX-ERP-CRM-v1.0.0.zip
cd VentureX-ERP-CRM

Step 3: Install Dependencies
composer install
npm install
npm run build

Step 4: Configure Environment
cp .env.example .env
php artisan key:generate
Edit .env with your database credentials.

Step 5: Setup Database
php artisan migrate --seed

Step 6: Start
php artisan serve

Open http://localhost:8000 — the 6-step installation wizard will guide you.

DEMO CREDENTIALS (after migrate --seed):
Super Admin: demo_admin@example.com / Demo_Admin_2026!
CEO: demo_manager@example.com / Demo_Manager_2026!
Sales Manager: demo_sales@example.com / Demo_Sales_2026!

DOCKER (Optional)
docker-compose up -d

AI SETUP (Optional)
All AI features work without API keys using built-in local intelligence.
For enhanced AI, add NVIDIA_API_KEY=nvapi-xxx to your .env file.
Get a free key at https://build.nvidia.com

UPDATES
Pull latest code, then:
composer install && npm install && npm run build
php artisan migrate
Always backup your database before updating.
```
