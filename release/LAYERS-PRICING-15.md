# VentureX ERP & CRM — 15-Layer Add-On Model (Codester / Payhip packages)

> **This document is included only in select marketplace packages (e.g. Codester and Payhip) for transparency.** It describes the intended layered add-on model. Availability, pricing, and release order may change. Nothing here is a guaranteed future feature except what is delivered in your purchased version.

## How layers work (concept)
- **Core**: the base ERP+CRM application package you purchased (self-hosted/deployable as per included documentation).
- **Layers** are optional add-ons that unlock extra capabilities or services. Some are **software entitlements** (checked in-app), some are **service offerings** (delivered by the publisher/partner), and some are **usage-based** (e.g. metered AI credits) when enabled.
- Entitlements are designed so that if a paid subscription/layer expires, **your data remains intact** and **exports remain available**; only gated premium features are disabled until renewed (exact behavior per installed version).
