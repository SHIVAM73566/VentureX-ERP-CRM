Step 1:
Create Your Database
VentureX needs a MySQL database. We'll create it, set up a user, and grant permissions.
💾 Create DB
👤 Create User
🔒 Grant Access
Open MySQL
You can use phpMyAdmin or the MySQL terminal
🌐
phpMyAdmin
http://localhost/phpmyadmin
⌨
Terminal
mysql -u root -p
Tip: This tutorial uses the MySQL terminal, but the same SQL works in phpMyAdmin's SQL tab.
Create the Database
Run this SQL command to create the database
MySQL Terminal
mysql>
CREATE DATABASE venturex_erp
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
Query OK, 1 row affected
✓ Database 'venturex_erp' created!
Create a Database User
Create a dedicated user for the application
MySQL Terminal
mysql>
CREATE USER 'venturex_user'@'localhost'
IDENTIFIED BY 'your_secure_password';
Query OK, 0 rows affected
✓ User 'venturex_user'@'localhost' created!
Important: Replace your_secure_password with a strong, unique password. You'll need this for the .env configuration later.
Grant Privileges
Give the user full access to the VentureX database
MySQL Terminal
mysql>
GRANT ALL PRIVILEGES
ON venturex_erp.*
TO 'venturex_user'@'localhost';
Query OK, 0 rows affected
✓ Privileges granted!
Flush Privileges
Reload the grant tables so changes take effect immediately
MySQL Terminal
mysql>
FLUSH PRIVILEGES;
Query OK, 0 rows affected
✓ Privileges flushed!
EXIT;
Bye
✓
Database Ready!
Your database is set up and the user has full access. Next, we'll configure the environment file.
Summary
