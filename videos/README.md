## What's Included

- **Scripts** — Full production-ready scripts with timestamps, screen directions, voiceover text, and pre-recording checklists
- **SRT Subtitles** — Standard SRT subtitle files for each video, ready to upload to YouTube/Vimeo
- **HTML Player** — Interactive browser-based viewer for all scripts and subtitles

## Recording Requirements

- Screen recording: 1920x1080 @ 30fps minimum
- Browser zoom: 100%
- Terminal font: 14pt+
- Clean desktop (no personal tabs/bookmarks visible)
- Demo data pre-seeded (php artisan migrate --seed)
